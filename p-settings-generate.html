Alula Editor™

Warning [READ]

This generates a Regular or Post-Solstice, Beated or Not save file for OneShot, for those who lost their save but want to play OneShot or to mod OneShot: Fading Memory without replaying the base game.

Do NOT use if You haven't beaten Solstice yet, since you'd be missing a ton of context.

If you want a full save, You need fill Your In-Game Name and check all checkboxes.

Also, You may consider replaying the base game with OneShot: Fading Memory installed anyway, since there are subtle easter eggs you might find.

Again, there's nothing stopping you from using this website if you haven't finished the full game. But trust me, I recommend you to finish the entire game properly with the Solstice route for the full experience.

With great power, comes great responsibilities.

Player's Name & State

In-Game Name
Changes the name that Niko & others call you in-game. Preferrably, no weird symbols (e.g ★ and etc.)
Times Game Cleared (max 999)
Tracks total successful plays. Affects specific dialogue variations (e.g George)
Times Talked to Rue (max 999)
Tracks total interactions with Rue. Affects certain event triggers.

Switches/Flags

Beat Solstice
Flags the Solstice route as completed.
Beat the game once
Indicates at least one ending has been reached.
Smashed lightbulb once
Whether the player has chosen to destroy the lightbulb in a previous run.
Saved world once
Whether the player has chosen to return the lightbulb in a previous run.
Talked to Rue for first time
[Limited info] Manages Niko's relationship with Rue.
Known Rue's Name
[Limited info] Allows Niko to refer to Rue by name in dialogue. [or] Manages Niko's relationship with Rue.
Picked Memory at Title
[Limited info] Whether the player chose to continue as The World Machine at the main menu.
