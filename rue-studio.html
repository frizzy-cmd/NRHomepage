A scene maker [& scripting engine] for OneShot.

What IS Rue Studio?

  • Rue Studio is an in-game scene maker and possibly a scripting engine for OneShot. It allows modders, content creators, creators, and everyone to script custom scenes, dialogues, player movement, and etc directly thru a simple external text file (ruestudio.txt) without needing to touch code.

Features & capabilities

Rue Studio processes custom scripts you make in ruestudio.txt on the fly with type checking, detailed logging, and built-in error handling.

  • Dialogues: Standard face-dialogue boxes, TWM/Entity text (@ed), document notes (@doctext), simulated desktop messages, (@desktoptext), and end credits text (@creditstext).
  • Audio: Trigger background music (@bgm), sound effects (@se/@sfx), and musical effects (@me) pre-dialogue or during dialogue playback.
  • Movement & direction: Sprite movement (@move.niko), instant movement (@move.niko.instant), and sprite direction controls (@face.niko).
  • Native OS boxes: (@edtext.info, @edtext.err, and interactable @edtext.yesno prompts).
  • Automatic documentation: Auto-generates a complete syntax reference guide (ruestudio_documentation.txt) right in your OneShot directory on first launch.

Additional features

  • Validation: Validates missing tags, missing audio/image files, text length limits, etc, before running with prompts to continue anyway or abort.
  • Logging: Detailed executing and error tracking logged to ruestudio_output.txt with the file size capped to 35MB (to avoid storage issues) and auto delete output file on exit.
  • Commenting: Full support for single-line (//) and multi-line block comments (/* ... */) to disable sections of code.

Controls & triggering

  • Default keybind: Press the L key in-game (or whichever key is bound to Input::L in your F1 setup) to run you code in ruestudio.txt.

Installation

  1. Locate your installed OneShot root directory.
  2. Navigate into the Data/ directory inside your OneShot folder.
  3. Move your original xScripts.rxdata file to a safe location.
  4. Place the modified xScripts.rxdata containing Rue Studio inside the Data/ folder.
  5. Launch OneShot normally. ruestudio.txt, ruestudio_documentation.txt and ruestudio_output.txt will automatically generate in your OneShot game directory.

Paths to OneShot

Windows: C:\Program Files (x86)\Steam\steamapps\common\OneShot\Data
 Linux:   ~/.steam/steam/steamapps/common/OneShot/Data
 macOS:   ~/Library/Application Support/Steam/steamapps/common/OneShot/Data

Troubleshooting

Q: My game crashes immediately upon launch.
A: Make sure you have replaced your unmodified xScripts.rxdata with the Rue Studio xScripts.rxdata version, Or, if in some cases, OneShot pushed an update that broke the mod. And, to end your game if the game crashed, you will have to open Task Manager, and end the process there.

Q: How do I revert back to the original vanilla game?
A: Restore your backed-up xScripts.rxdata file, or verify game file integrity via Steam properties.

Q: Windows Defender/my antivirus flags the file (.rxdata) as a virus
A: This shouldn't happen, since it's not happening for me on Windows Defender, (W10 LTSC), Add the .rxdata as a exclusion to the antivirus. I assure you it's safe, literally open source. If you don't trust me, you can extract the .rxdata and find out, or look at the .rb file i uploaded.
