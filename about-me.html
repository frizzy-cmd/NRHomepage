How do i make OneShot mods? It's pretty complicated, but i'll try to simplify and cut down some processes into this description:
Step 1: Extraction
You'd have to extract the xScripts.rxdata in your OneShot folder (Data/xScripts.rxdata), after extracting, there will be plenty of .rb files (Ruby). That's normal.
Step 2: Code
Personally, i'd make a new file called 110 - [mod name].rb, for example 110 - Calamus_Toolkit.rb, then code some shit in there.
Step 3: Repack
You'd have to repack it back up. I made a custom .rb file for both extracting & repacking, so i run ruby extractor.rb, it repacks the extracted .rb files into xScripts.rxdata, i put it back in the Data folder, then test. Any errors, fix, repack, repeat.
