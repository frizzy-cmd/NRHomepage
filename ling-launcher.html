A simple PyQt6 launcher for OneShot.

What IS Ling Launcher?

  • Ling Launcher is a simple PyQt6 launcher for OneShot, it features save profiles, easy mod selection, meaning you don't have to manually install .rxdatas and move them into your Data folder! And much more features. Go download it, and check the features!

Additional information

  • Ling Launcher does NOT collect any data, information, telemetry, or any sort of data collection. Go check out the .py i uploaded, if you're second guessing.
  • ..honestly, its pretty simple and self explanatory. If you have any questions on how to use Ling Launcher or any other of my mods/tools/projects, hit me up at support.kipsite@gmail.com, Or try reverse engineering it via the .py file.

Installation

  1. Download the .exe file
  2. Run it
  3. Enjoy!

    4. Troubleshooting

    Q: Windows Defender/my antivirus flags the file (.rxdata) as a virus
    A: This shouldn't happen, since it's not happening for me on Windows Defender, (W11 Pro), Add the .exe as a exclusion to the antivirus. I assure you it's safe, literally open source. If you don't trust me, you can extract the .exe and find out, or look at the .py file i uploaded.

    Q: How do I uninstall it?
    A: Simply delete the .exe file. Make sure to switch to a profile of yours before uninstalling! Otherwise, you may not be able to switch back. You can still switch, but it's a bit advanced.
