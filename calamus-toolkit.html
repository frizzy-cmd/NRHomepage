What is Calamus Toolkit?

Calamus Toolkit is a OneShot mod, providing tools for modders or experimentors to tinker around with in OneShot! There are diagnostic tools, teleporting, and so much more.
Version: v0.5.4-GA [General Availability] Developers: Kip, OTC Platforms: Windows | macOS | Linux License: GPL-3.0

!! Warning !!

Please finish the base game and Solstice route before using this toolkit. Using CalamusToolkit when you haven't beat the game will spoil and break the game's story and functions. No one's stopping you, but it's heavily recommended.

What does Calamus Toolkit have?

Toolkit options:

  • Walk Anywhere: This is the key feature that I personally love! You can clip thru ANYTHING. Allowing Niko to go thru walls, barriers, and more!
  • Map ID Jumper: You can bypass progression by force-teleporting Niko to any Map ID (001-999) instantly! Spawning at X:15 Y:15 for every map, since i dont want to build a system where it can detect walkable area, Usually, X:15 Y:15 is the OK area for most maps to walk around!
  • BGM Jukebox: You can customize what background music you want! Go to reference.txt/Additional files/musicids.txt for the list of the available IDs, or, go to your OneShot game directory and find calamus_bgm_log.txt!
  • Engine Switches Inspector: Toggle or change the values of the in-game switches (e.g. locks, states, etc)
  • Item Spawner: You can instantly spawn items using their specific IDs, (IDs will be listed in reference.txt/Additional files/itemids.txt!) You can spawn a bottle of alcohol, wet sponge, or wool, well almost anything! (in the game)
  • ..and much much more

Installation

  1. Locate your installed OneShot root directory.
  2. Navigate into the Data/ directory inside your OneShot folder.
  3. Move your original xScripts.rxdata file to a safe location.
  4. Download the modified xScripts.rxdata from this page and place it inside the Data/ folder.
  5. Launch OneShot normally.

Paths to OneShot

Windows: C:\Program Files (x86)\Steam\steamapps\common\OneShot\Data
 Linux:   ~/.steam/steam/steamapps/common/OneShot/Data
 macOS:   ~/Library/Application Support/Steam/steamapps/common/OneShot/Data

Troubleshooting

Q: My game crashes immediately upon launch.
A: Make sure you have replaced your unmodified xScripts.rxdata with the CalamusToolkit xScripts.rxdata version, Or, if in some cases, OneShot pushed an update that broke the injector. And, to end your game if the game crashed, you will have to open Task Manager, and end the process there.

Q: How do I revert back to the original vanilla game?
A: Restore your backed-up xScripts.rxdata file, or verify game file integrity via Steam properties.

Q: Windows Defender/my antivirus flags the file (.rxdata) as a virus
A: This shouldn't happen, since it's not happening for me on Windows Defender, (W10 LTSC), Add the .rxdata as a exclusion to the antivirus. I assure you it's safe, literally open source. If you don't trust me, you can extract the .rxdata and find out, or look at the .rb file i uploaded.

Q: Why is there a command prompt when i launch the game and when i check for updates?
A: For checking updates. The function uses powershell to check for the latest release, so theres your answer. I promise you, nothing shady. You can check the code yourself, like i said above.

If a problem you are having is not listed here, please contact me, or try to fix it yourself.
