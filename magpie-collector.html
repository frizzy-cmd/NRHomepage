A collector/logger for OneShot.

What IS Magpie Collector?

  • Magpie Collector is a debugger/logger/console/collector/oranythingyoucall it, for OneShot. obviously. Magpie Collector logs all dialogue boxes that get triggered and creates a harmless magpie_diag_log.txt file in your OneShot game directory, and logs all dialogue boxes and info there.

What does Magpie Collector collect?

Magpie Collector logs this information in-game. (Don't worry a single bit. Your data isn't getting sent to China or anyone.)

  • DialogueFace: Displays the active sprite on the dialogue box as of when the dialogue box was triggered.
  • Content: Displays the text on the dialogue box as of when the dialogue box was triggered.
  • Subcontent: [if applicable] Displays the subcontent on the dialogue box as of when the dialogue box was triggered.
  • Triggered: Displays the date and time as of when the dialogue box was triggered

Misc. info

  • Map ID at trigger: Displays the current Map ID as of when the dialogue box was triggered | Coords (X, Y): Displays the current coordinates of Niko as of when the dialogue box was triggered
  • BGM at trigger: Displays the current background music playing as of when the dialogue box was triggered
  • Event count at trigger: Displays the current events around Niko as of when the dialogue box was triggered
  • Player orientation at trigger: Displays the orientation of Niko as of when the dialogue box was triggered (e.g if facing left, then Left)
  • Windows pos at trigger: Displays the position of the dialogue box as of when the dialogue box was triggered, Commonly Bottom

Game statistics

  • Inventory count at trigger: Displays the current total of items in Niko's inventory as of when the dialogue box was triggered.
  • Inventory content at trigger: Displays the items in Niko's inventory as of when the dialogue box was triggered.

Save & misc. statistics

  • Last save time at trigger: Displays a timestamp of when the last save file was saved/modified as of when the dialogue box was triggered. (Untested, may not work)
  • Save file loaded at trigger: Displays the save file loaded as of when the dialogue box was triggered. (Untested, probably doesn't work)
  • Playtime at trigger: Displays the user's playtime of when the dialogue box was triggered. (Inaccurate)
  • Framerate [engine] at trigger: Displays the game's FPS as of when the dialogue box was triggered.
  • Framerate [client] at trigger: Displays the client's FPS as of when the dialogue box was triggered.
  • Variables active at trigger: Displays the current active variables as of when the dialogue box was triggered.

Installation

  1. Locate your installed OneShot root directory.
  2. Navigate into the Data/ directory inside your OneShot folder.
  3. Move your original xScripts.rxdata file to a safe location.
  4. Download the modified xScripts.rxdata from this page and place it inside the Data/ folder.
  5. Launch OneShot normally.

Paths to OneShot

Windows: C:\Program Files (x86)\Steam\steamapps\common\OneShot\Data
 Linux:   ~/.steam/steam/steamapps/common/OneShot/Data
 macOS:   ~/Library/Application Support/Steam/steamapps/common/OneShot/Data

Troubleshooting

Q: My game crashes immediately upon launch.
A: Make sure you have replaced your unmodified xScripts.rxdata with the MagpieCollector xScripts.rxdata version, Or, if in some cases, OneShot pushed an update that broke the injector. And, to end your game if the game crashed, you will have to open Task Manager, and end the process there.

Q: How do I revert back to the original vanilla game?
A: Restore your backed-up xScripts.rxdata file, or verify game file integrity via Steam properties.

Q: Windows Defender/my antivirus flags the file (.rxdata) as a virus
A: This shouldn't happen, since it's not happening for me on Windows Defender, (W10 LTSC), Add the .rxdata as a exclusion to the antivirus. I assure you it's safe, literally open source. If you don't trust me, you can extract the .rxdata and find out, or look at the .rb file i uploaded.

Q: Will this collect all dialogues that appear on my screen? Can I toggle it?
A: Yes, this will collect all dialogues that have been triggered by the player. Unfortunately, you can't toggle it on/off. Only if you remove the MagpieCollector xScripts.rxdata.

If a problem you are having is not listed here, please contact me, or try to fix it yourself.
